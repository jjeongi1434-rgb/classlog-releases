# 클래스로그 (ClassLog) 설치 파일

컴시간 시간표와 연동해 출결·활동 기록·진도·시험·출결 통계·세특 초안을 관리하는 Windows 프로그램 **클래스로그**의 설치 파일을 올려 두는 곳입니다.

- 설치: [Releases](../../releases/latest)에서 `ClassLog-Setup-버전.exe`를 받아 실행하세요. 관리자 권한은 필요 없습니다.
- 업데이트: 한 번 설치하면, 프로그램을 켤 때 이곳에서 새 버전을 확인해 자동으로 받아 둡니다.
- 학생 기록은 각 선생님 PC에만 저장되고, 이곳이나 인터넷 어디에도 올라가지 않습니다.
- 코드 서명이 없어 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
